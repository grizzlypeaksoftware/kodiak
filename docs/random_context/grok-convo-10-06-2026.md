**Your read, which held up.** Stealing weights is the least valuable move. Checkpoints are big, access-controlled, and age fast. The prize is the recipe: data mix, ablations, training code, know-how. Distillation already copies a lot of capability from outputs without theft. Tooling (Claude Code, Grok Build, Codex) is the harness, not the weights, and is harder to reproduce from a stolen snapshot. Chinese labs are already close: composite gap reported around 3% this week, Chinese open-weight models (Kimi, GLM, Qwen, DeepSeek) near the closed frontier, often a few months behind rather than years. Spy-theft matters less if the thing worth stealing is already downloadable.

**Self-training.** Claude helping you train is not the model training itself. The open loop is: propose a change, run the experiment, keep the winner, no human as the filter. Pieces exist (agents writing training code, AlphaEvolve-style search, self-play inside games). Missing piece is selection outside a game: no scoreboard, Goodhart, model collapse if it only trains on its own outputs. Backprop is already automated. Meta-learning is the hard part because the reward is slow and sparse. A model cannot see its own weights; it still has to go through an external loop.

**What you can actually build.** Full self-improvement needs many full training runs. On a DGX the realistic version is AlphaEvolve-lite: model proposes one change, cheap eval, you keep the winner. You are already close: Claude Code as the harness, it suggests experiments, you add feedback. The untested bit is whether the proposer gets better as it sees your accept/reject log.

**Claude terms.** Consumer Pro/Max bans automated non-human access except via official paths. The Agent SDK is the sanctioned route and includes a separate monthly credit on Pro/Max. API allows automation, but Anthropic bars using outputs to train competing models without permission. You are not competing. You generate synthetic data on DigitalOcean Inference Cloud, not on Claude outputs. Training data for Kodiak was written by open models (gpt-oss-120b, DeepSeek-V3.2). Consumer chats train Anthropic’s models unless you opt out.

**Kodiak.** Encoder-only decision model on an Ettin/ModernBERT backbone, not an LLM. v0.2 1B on Hugging Face (`cortex-agent-llc/kodiak-v0.2-1b`): never-seen forced accuracy about 0.689, matches Qwen3-8B on that metric at roughly 40× speed, abstain precision about 0.88–0.90, about 38 ms on GPU. Public Decision Index around 17.2, mid-pack overall, strong among ≤2B, good on intent routing, weak on hallucination checks and API calls. Jump from 400M to 1B was only a few points. Do not scale for the wording problem.

**Wording trap.** Reworded options flip answers about a third of the time. More reworded data did not fix it. It is a representation problem, not coverage. Next moves: adversarial or consistency loss so identical decisions with different wording must agree; a perturbation script (synonym swap, reorder, filler) rather than an LLM generator, because Kodiak cannot write rewordings; consistency eval as a guard; audit the synthetic generator for label-overlap bias. Abstain threshold is the other lever.
